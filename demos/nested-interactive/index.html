iScroll nested interactive demo

Embedded interactive region

This demo uses preventScrollException so the mock map below keeps its own drag, click and wheel behavior while the surrounding content still uses iScroll.

  1. Drag inside the map to move the colored markers.
  2. Scroll or drag outside the map to move the page.
  3. Use the mouse wheel over the map to change the zoom level.
  4. Tap or click inside the map to increment the click counter.
